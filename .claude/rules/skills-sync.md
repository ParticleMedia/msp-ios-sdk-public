# Skills System

## What Are Skills?

Skills are documented procedures for completing specific types of tasks. They live in
`.agents-shared/skills/` (shared across all agents) and `.claude/skills/` (mirrored copy).

## Progressive Loading

1. **Startup** (this rule): Only skill names and descriptions loaded (below)
2. **On demand**: When a task matches a skill, READ the full `.agents-shared/skills/{name}.skill.md` file

## Sync Rule

When creating or modifying skill files:
- `.claude/skills/` and `.agents-shared/skills/` must stay identical
- Write the primary change first, then sync the copy
- `.claude/skills/` is NOT a fork — it is a mirror of `.agents-shared/skills/`
